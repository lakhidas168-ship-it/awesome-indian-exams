# CUET PG

CUET PG is the common entrance for master's programmes at central universities and other
participating universities, institutions and autonomous colleges. The National Testing Agency
conducts it in computer-based mode; each university then counsels and admits on the CUET PG
score. The 2026 cycle was held 6–27 March 2026; the next cycle's bulletin is awaited on the
portal below.

## At a glance

| | |
|---|---|
| Conducted by | National Testing Agency |
| Stages | Computer-based test → university-wise counselling and admission |
| Mode | Computer-based test only |
| Papers | Up to 4 question-paper codes per candidate |
| Pattern per paper | 75 multiple-choice questions, 90 minutes, +4 correct / −1 incorrect (75 × 4 = 300 max) |
| Medium | English and Hindi (bilingual), except language papers, M.Tech/Higher Sciences (English only) and Acharya papers (Sanskrit, with exceptions) |
| Eligibility | Bachelor's degree passed, or final-year Bachelor's student appearing in 2026; no NTA age bar (universities may set their own) |
| 2026 scale | 157 subjects; 292 exam cities including 16 outside India |

## Exam pattern

Each question paper is one 90-minute computer-based paper of 75 multiple-choice questions.
Each question carries 4 marks: +4 for a correct response, −1 for an incorrect response, 0 for
unanswered or marked-for-review questions. If a question is dropped or has no correct option,
all candidates who appeared get +4 for it.

A candidate may choose up to 4 question-paper codes, matching the codes each target
university maps to its programmes. Application fee (2026 cycle, up to two papers, plus
service charges): General ₹1,400; Gen-EWS / OBC-NCL ₹1,200; SC / ST / Third Gender ₹1,100;
PwD ₹1,000; outside India ₹7,000 — plus a per-extra-paper charge (₹700 General,
₹600 reserved categories, ₹3,500 outside India).

## Syllabus

The syllabus is the subject's undergraduate-level syllabus, fixed per question-paper code
(Appendix II of the bulletin; full list on the portal). Check the exact paper code each
university demands for your programme before registering — similar courses at different
universities can map to different codes.

## How to prepare (free, in order)

1. Pick target universities first, then note the exact question-paper code each one wants.
2. Download the bulletin and your paper's syllabus from the portal above.
3. Revise the undergraduate subject core from standard textbooks and NCERTs where relevant.
4. Practise 75-question, 90-minute mocks with the +4/−1 scheme — skip rather than guess blind.
