# TG (Telangana) EAPCET

> **Evidence status: ✅ verified.** This page gives the structure and the official links. All numbers are cross-checked against the 2026 official instruction booklet and detailed notification.

TG EAPCET is Telangana's entrance for engineering, agriculture and pharmacy seats in the state, conducted by JNTUH for TGCHE.

## At a glance

| | |
|---|---|
| Conducted by | JNTUH (on behalf of TGCHE) |
| Exam mode | Computer-based test (CBT) |
| Duration | 3 hours |
| Total questions | 160 |
| Sessions per day | Two (forenoon 09:00–12:00, afternoon 15:00–18:00) |
| Stages | Computer-based test → counselling |
| Medium | Bilingual: English–Telugu or English–Urdu (candidate chooses one) |
| Normalisation | Yes, across sessions (same syllabus, same pattern) |

## Exam pattern

A computer-based test in Mathematics, Physics and Chemistry for engineering (Biology replaces Mathematics for agriculture and pharmacy).

| Subject | Questions | Marks |
|---|---|---|
| Mathematics | 80 | 80 |
| Physics | 40 | 40 |
| Chemistry | 40 | 40 |
| **Total** | **160** | **160** |

- Each question carries **one mark**.
- All questions are objective type (multiple choice).
- No negative marking.

## Courses offered (Engineering stream)

**B.E. / B.Tech.** in: Engineering, Biotechnology, Dairy Technology, Agricultural Engineering, Food Technology, Biomedical Engineering, Pharmaceutical Engineering.

**Other professional courses:** B.Pharmacy (50% seats via MPC), Pharm-D (50% MPC / 50% BiPC), B.Sc. (Hons.) Agriculture, B.Sc. (Hons.) Horticulture, B.V.Sc. & A.H., B.F.Sc., B.Sc. (Nursing).

## Eligibility (Engineering / B.Pharmacy MPC / B.Tech Dairy / Ag. Engg / FT)

| Criterion | Requirement |
|---|---|
| Nationality | Indian / PIO / OCI card holder |
| Domicile | Must satisfy Telangana local / non-local status (Telangana Educational Institutions Order, 1974 as amended) |
| Qualifying exam | Passed or appeared Intermediate (10+2) with **Mathematics, Physics, Chemistry** (or related vocational in Engineering/Tech) from Board of Intermediate Education, Telangana, or equivalent. Diploma in Engineering from SBTET Telangana also accepted. |
| Minimum marks | **45%** in MPC taken together ( **40%** for reserved categories ) |
| Age (Engineering / Pharmacy) | **16 years** completed as on 31-12-2026. No upper age limit. |
| Age (B.Tech Dairy Tech / Ag. Engg / FT) | **17 years** as on 31-12-2026; upper limit **22 years** ( **25 years** for SC/ST ) |

## Syllabus

Telangana Intermediate (Class 11–12) syllabus, NCERT-aligned. Mathematics, Physics and Chemistry as per the official syllabus published on the TG EAPCET website.

## How to prepare (free, in order)

1. **Mathematics carries the most weight (80/160)** — prioritise it.
2. Cover the full Telangana Intermediate / NCERT syllabus for all three subjects.
3. Practice previous years' TG EAPCET papers (available on the official site under "Mock Test" or from the instruction booklet model questions).
4. Take the official mock test on the website to get familiar with the CBT interface.
