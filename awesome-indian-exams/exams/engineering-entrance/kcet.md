# Karnataka CET (KCET)

> **Evidence status: 🟡 secondary.** The facts below were cross-checked against several non-official sources on
> 2026-09-27. Confirming them against the official notification is a hive task. Always read the current notice
> before you apply or pay a fee.

KCET is Karnataka's entrance for engineering, agriculture, pharmacy and other professional courses in the
state. Candidates from Karnataka also take a Kannada language test if required.

## At a glance

| | |
|---|---|
| Conducted by | Karnataka Examinations Authority (KEA) |
| Mode | Pen and paper (OMR) |
| Per subject | 60 questions, 60 marks, 80 minutes |
| Negative marking | None |

## Official sources

- Karnataka Examinations Authority (official): <https://kea.kar.nic.in>

## Exam pattern

Separate papers for Mathematics, Physics, Chemistry and Biology, each 60 questions for 60 marks in 80 minutes,
one mark per question, no negative marking. Engineering uses PCM. The engineering rank combines the CET marks with
Class 12 PCM marks (see the brochure).

## Syllabus

Karnataka PUC (Class 11–12) syllabus for the subjects, NCERT-aligned.

## How to prepare (free, in order)

1. No negative marking: answer every question.
2. Board marks also count towards the rank, so don't neglect Class 12.
