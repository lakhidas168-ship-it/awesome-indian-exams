# MHT CET (PCM)

> **Evidence status: 🟡 secondary.** The facts below were cross-checked against several non-official sources on
> 2026-09-27. Confirming them against the official notification is a hive task. Always read the current notice
> before you apply or pay a fee.

MHT CET is Maharashtra's entrance for engineering, pharmacy and agriculture seats in the state. This page
covers the PCM group.

## At a glance

| | |
|---|---|
| Conducted by | State CET Cell, Maharashtra |
| PCM paper | 150 questions, 200 marks, 180 minutes, computer-based |
| Negative marking | None |

## Official sources

- State CET Cell, Maharashtra (official): <https://cetcell.mahacet.org>

## Exam pattern

| Paper | Questions | Marks per question | Marks | Time |
|---|---:|---:|---:|---|
| Mathematics | 50 | 2 | 100 | 90 min |
| Physics + Chemistry | 100 | 1 | 100 | 90 min |

About 20% of the questions come from the Class 11 syllabus and 80% from Class 12. There is no negative marking.

## Syllabus

Maharashtra State Board Class 11–12 PCM, broadly aligned with NCERT. The CET Cell publishes the chapter list.

## How to prepare (free, in order)

1. With no negative marking, attempt every question.
2. Class 12 carries about 80% of the marks: prioritise it.
