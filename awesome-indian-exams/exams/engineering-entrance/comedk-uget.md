# COMEDK UGET

> **Evidence status: 🟡 secondary.** The facts below were cross-checked against several non-official sources on
> 2026-09-27. Confirming them against the official notification is a hive task. Always read the current notice
> before you apply or pay a fee.

COMEDK UGET is the entrance for engineering seats in private colleges in Karnataka that belong to the
consortium.

## At a glance

| | |
|---|---|
| Conducted by | Consortium of Medical, Engineering and Dental Colleges of Karnataka (COMEDK) |
| Mode | Computer-based, 3 hours |
| Total | 180 questions, 180 marks |
| Negative marking | None |

## Official sources

- COMEDK (official): <https://www.comedk.org>

## Exam pattern

Physics, Chemistry and Mathematics, 60 questions each, one mark per question, no negative marking.

## Syllabus

Class 11–12 PCM (NCERT-aligned); COMEDK publishes the detailed syllabus.

## How to prepare (free, in order)

1. No negative marking: attempt all 180.
2. Speed practice: one minute per question.
