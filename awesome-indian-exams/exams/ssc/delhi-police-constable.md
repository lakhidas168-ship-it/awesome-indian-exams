# Delhi Police Constable (Executive)

> **Evidence status: 🟡 secondary.** The facts below were cross-checked against several non-official sources on
> 2026-09-27. Confirming them against the official notification is a hive task. Always read the current notice
> before you apply or pay a fee.

SSC conducts the recruitment of Constables (Executive) for Delhi Police.

## At a glance

| | |
|---|---|
| Conducted by | Staff Selection Commission for Delhi Police |
| Stages | CBT → physical endurance and measurement test → medical |
| Qualification | Class 12 pass (see notice) |

## Official sources

- SSC official website (notices, syllabus, answer keys): <https://ssc.gov.in>

## Exam pattern

**CBT:** 100 questions, 100 marks, 90 minutes, **−0.25** per wrong answer.

| Section | Marks |
|---|---:|
| General Knowledge and Current Affairs | 50 |
| Reasoning | 25 |
| Numerical Ability | 15 |
| Computer Fundamentals | 10 |

## Syllabus

GK and current affairs (the largest part), reasoning, basic arithmetic, and computer fundamentals (MS Office,
internet, basics).

## How to prepare (free, in order)

1. GK is half the paper: daily current affairs from PIB plus NCERT static GK.
2. Start the running practice on day one.
