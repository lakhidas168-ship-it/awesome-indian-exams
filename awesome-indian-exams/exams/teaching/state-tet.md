# State TETs (UPTET, REET, MAHA TET and others)

> **Evidence status: ⚪ unverified.** This page gives the structure and the official links. Numbers that could not be
> cross-checked are left to the official notification. Verifying them is a hive task.

A Teacher Eligibility Test (TET) is required to teach Classes 1–8 in government schools. The central test is
[CTET](ctet.md); each state also runs its own TET for its schools. All TETs follow the NCTE framework, so the structure
is the same everywhere: Paper I for Classes 1–5, Paper II for Classes 6–8. The dates, fees and language papers differ by
state.

## At a glance

| | |
|---|---|
| Framework | National Council for Teacher Education (NCTE) |
| Papers | Paper I (Classes 1–5), Paper II (Classes 6–8); take one or both |
| Conducted by | Each state's board or commission (table below) |
| Result | An eligibility certificate, not a job: recruitment is a separate exam |

## Official sources

- NCTE (framework and TET guidelines): <https://ncte.gov.in>
- REET: Board of Secondary Education, Rajasthan: <https://rajeduboard.rajasthan.gov.in>
- UPTET: Uttar Pradesh Education Service Selection Commission: <https://upessc.up.gov.in>
- CTET, the central TET (CBSE): <https://ctet.nic.in>

## Exam pattern

Every TET that follows the NCTE framework has the same five blocks. The state's notification has the number of
questions, time and qualifying marks.

| Block | Paper I (Classes 1–5) | Paper II (Classes 6–8) |
|---|---|---|
| Child development and pedagogy | yes | yes |
| Language I | yes | yes |
| Language II | yes | yes |
| Mathematics | yes | Mathematics and science teachers |
| Environmental studies | yes | — |
| Social studies | — | Social studies teachers |

## Syllabus

The state's TET syllabus follows the NCTE framework at the level of the classes you want to teach: the state
board's own textbooks, plus child development and pedagogy. Language I is usually the state's language, so check which
languages your state offers.

## How to prepare (free, in order)

1. Start with child development and pedagogy: it is in both papers and in CTET too.
2. Use the state board's own textbooks for the content blocks, as the questions follow them.
3. Take CTET as well: one preparation, a certificate valid for central and many state schools.
4. Bookmark only the official site: fake TET portals and look-alike domains are common.
