# PSU recruitment for Electrical Engineering graduates

> **Evidence status: ⚪ unverified.** This is a starting list of PSUs that hire electrical engineers, with their
> official websites. Which PSUs use GATE scores changes from year to year. Hive task `T-007` records each
> PSU's latest recruitment channel from its official advertisement.

Many central PSUs hire graduate engineers as trainees using the **GATE score** (then a group discussion and/or
interview). Others run their **own written test**. A strong [GATE EE](gate-ee.md) score is the one preparation
that keeps most of these doors open.

## At a glance

| | |
|---|---|
| Typical entry post | Engineer / Executive / Management Trainee |
| Usual route | GATE score → shortlist → GD/interview. Some PSUs use their own CBT instead |
| When | PSUs usually advertise GATE-based hiring after the GATE result (March–May). Check each site |
| Rule of thumb | Every advertisement names the GATE year it accepts. An older score may not count |

## Exam pattern

Set per advertisement:

- **GATE-based:** GATE score (usually a large weight) + group discussion and/or interview. Some PSUs add a
  medical examination.
- **Own exam:** an objective CBT on the EE syllabus plus aptitude, then an interview.

## Syllabus

GATE-based hiring uses the [GATE EE syllabus](gate-ee.md#syllabus). Own-exam PSUs publish a syllabus in the
advertisement, usually the GATE EE core.
