# BARC OCES/DGFS (Scientific Officer)
<!-- evidence-status: secondary (official notification for current cycle not available) -->

The Orientation Course for Engineering Graduates and Science Postgraduates (OCES) and the DAE Graduate Fellowship Scheme (DGFS) are the primary pathways to becoming a Scientific Officer (Group A) in the Department of Atomic Energy (DAE).

## At a glance

| | |
|---|---|
| Conducted by | Bhabha Atomic Research Centre (BARC) |
| Exam mode | Computer-based test (CBT) |
| Selection process | Screening test (CBT) followed by an interview |
| Eligibility | B.E./B.Tech/B.Sc.(Engg.)/5-year Integrated M.Tech with at least 60% aggregate marks. Final year students can apply. |
| Age limit | See the latest official notification for current age limits. |

## Official sources

- BARC official site: <https://barc.gov.in>
- BARC Careers page: <https://barc.gov.in/careers/index.html>

## Exam pattern

The screening test is a computer-based test. Please refer to the latest official notification for the exact number of questions, duration, and marking scheme.

## Syllabus

The syllabus for the screening test is based on the standard undergraduate curriculum for the respective engineering discipline.

## Free resources

- Official website for notifications: <https://barc.gov.in>

## How to prepare (free, in order)

1. **Master the core:** Focus on the [EE core](../../modules/ee-core.md) and [Engineering Mathematics](../../modules/engineering-mathematics.md) modules.
2. **Practice:** Solve previous years' BARC OCES screening test papers if available on the official website.
3. **Mock tests:** Use GATE-level mock tests to improve speed and accuracy, as the exam pattern is similar.
