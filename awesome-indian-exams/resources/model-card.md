# Awesome Indian Exams AI

This model is a specialized tutor for Indian competitive exams, designed to be free, open, and evidence-based.

## Evidence-Gate Behavior
This model is trained to prioritize factual accuracy by retrieving information from official sources. If the model cannot find a source for a claim, it is instructed to state: "not sure: check the official notification" and provide the relevant link.
