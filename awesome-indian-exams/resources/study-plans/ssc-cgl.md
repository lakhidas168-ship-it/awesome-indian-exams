# SSC CGL study plan: 6-month and 12-month tracks (free)

> Built from the shared modules mapped to `ssc-cgl` in `registry/exams.toml` and the
> [SSC CGL exam page](../../exams/ssc/ssc-cgl.md). The SSC CGL 2026 notice (F. No.
> HQ-C11018/1/2026-C-1) on <https://ssc.gov.in> is the authority for the syllabus and pattern:
> confirm the chapter list there. Everything recommended here is free and official; no paid or
> coaching material is used.

## How to use this plan

1. **Week 1, before studying:** solve one Tier 1 previous paper cold and timed, from the official SSC
   archive above. Tag every question with its module; the weakest module gets the earliest revision slots.
2. **Quant and reasoning first, accuracy before speed:** learn each chapter from NCERT Class 6–10
   mathematics, then solve that topic in official previous papers. Track accuracy and seconds per
   question per topic.
3. **English daily:** one newspaper editorial plus 20 grammar questions a day; error spotting, cloze
   test and idioms come from volume.
4. **Respect the penalties:** Tier 1 −0.50 and Tier 2 Sections 1–3 −1 per wrong answer reward skipping
   guesses; practise skipping in every mock.
5. **Last month: timed mocks and previous papers only**, no new topics.

## 12-month track (52 weeks)

| Weeks | Module(s) | Work (free sources) |
|-------|-----------|---------------------|
| 1–2 | Diagnostic | One Tier 1 previous paper cold, timed; read the notice syllabus on <https://ssc.gov.in> |
| 3–14 | [Quant](../../modules/quant-aptitude.md) | Arithmetic → algebra → geometry/mensuration/trigonometry → data interpretation; NCERT Class 6–10 base, then PYQs topic by topic |
| 15–22 | [Reasoning](../../modules/reasoning.md) | Analogies → series → coding-decoding → relations/syllogism → non-verbal; daily 20-question drills |
| 23–30 | [English](../../modules/english-language.md) | Comprehension + grammar + vocabulary; editorial reading continues daily |
| 31–38 | [General awareness](../../modules/general-awareness.md) | NCERT Class 6–10 social science and science for static GK; PIB for current affairs |
| 39–42 | [Computer awareness](../../modules/computer-awareness.md) | Basics to the Tier 2 Section 3 qualifying bar (15-minute, 20-question format) |
| 43–48 | Tier 2 depth + weakest-module second pass | Harder quant/reasoning/English sets; re-solve every tagged PYQ you got wrong |
| 49–52 | Mocks only | Full Tier 1 and Tier 2 papers timed, with section timers; re-solve mistakes after a week |
| 1–52 daily | [English](../../modules/english-language.md) + [General awareness](../../modules/general-awareness.md) | Editorial + 20 grammar questions; PIB current affairs |

## 6-month track (26 weeks)

Same order, compressed; start Tier 2-format practice from week 16.

| Weeks | Module(s) | Work (free sources) |
|-------|-----------|---------------------|
| 1 | Diagnostic | One Tier 1 previous paper cold, timed; read the notice syllabus |
| 2–7 | [Quant](../../modules/quant-aptitude.md) | Arithmetic-heavy fast pass, then algebra/geometry/DI from PYQs |
| 8–11 | [Reasoning](../../modules/reasoning.md) | High-frequency topics first (series, coding, analogies), then the rest |
| 12–15 | [English](../../modules/english-language.md) | Comprehension + error spotting + cloze; daily reading throughout |
| 16–19 | [General awareness](../../modules/general-awareness.md) | Static GK fast pass + last-12-months current affairs from PIB |
| 20–21 | [Computer awareness](../../modules/computer-awareness.md) | Qualifying-level basics in Tier 2 Section 3 format |
| 22–23 | Weakest modules only | Tagged PYQs you got wrong, re-solved under time |
| 24–26 | Mocks only | Full papers timed with section timers; no new topics |
| 1–26 daily | [English](../../modules/english-language.md) + [General awareness](../../modules/general-awareness.md) | Editorial + grammar; PIB current affairs |

## Weekly rhythm (both tracks)

- Six study days, one lighter day for revision and rest.
- Every week: one timed mock; spend as long analysing it as taking it, sorting mistakes into concept
  gap, silly mistake, time pressure or guess (see [study methods](../study-methods.md)).
- Every month: check remaining weeks against the official Tier 1 / Tier 2 dates and move unfinished
  modules forward.
