## Modules in study order

All three modules run in parallel every week (school-style), Class 11 blocks before Class 12 blocks.

| # | Module | Scope in this plan |
|---|--------|--------------------|
| 1 | [Physics (NCERT Class 11–12)](../../modules/ncert-physics.md) | Mechanics → thermo/waves → electromagnetism → optics → modern |
| 2 | [Chemistry (NCERT Class 11–12)](../../modules/ncert-chemistry.md) | Physical → inorganic (NCERT-line) → organic (mechanism practice) |
| 3 | [Mathematics (NCERT Class 11–12)](../../modules/ncert-mathematics.md) | Algebra → trigonometry/coordinate → calculus → vectors/3D/probability |

## How to use this plan

1. **Week 1, before studying:** solve one previous Paper 1 cold and timed, from the official NTA
   archive. Tag every question with its module and chapter; the weakest chapters get the earliest
   revision slots.
2. **NCERT first, then exemplar:** read each chapter in the NCERT textbook
   (<https://ncert.nic.in/textbook.php>), solve every exercise, then the NCERT exemplar problems for
   depth. Chemistry stays close to NCERT wording; physics needs derivation-by-hand once per formula.
3. **Numerical questions carry −1:** treat Section B like MCQs in practice and drill skipping guesses.
4. **NTA Abhyas for interface practice:** take mocks in the real computer-based interface, at the same
   time of day as the real session.
5. **Last sixth: full mocks and previous papers only**, no new chapters.

## 12-month track (52 weeks)

| Weeks | Module(s) | Work (free sources) |
|-------|-----------|---------------------|
| 1–2 | Diagnostic | One previous Paper 1 cold, timed; read the bulletin chapter list on <https://jeemain.nta.nic.in> |
| 3–16 | [Physics](../../modules/ncert-physics.md) + [Chemistry](../../modules/ncert-chemistry.md) + [Maths](../../modules/ncert-mathematics.md), Class 11 | Physics: mechanics, thermodynamics, waves. Chemistry: mole concept, atomic structure, thermodynamics, equilibrium. Maths: algebra, trigonometry, coordinate geometry start. NCERT exercises per chapter |
| 17–30 | [Physics](../../modules/ncert-physics.md) + [Chemistry](../../modules/ncert-chemistry.md) + [Maths](../../modules/ncert-mathematics.md), Class 12 | Physics: electrostatics → magnetism → optics → modern. Chemistry: organic mechanisms + remaining inorganic/physical. Maths: calculus, vectors/3D, probability. Exemplar problems per chapter |
| 31–40 | All three modules, second pass | NCERT exemplar + weak-chapter re-solves from your tagged PYQs; NIOS material (<https://www.nios.ac.in>) for any chapter that still resists |
| 41–46 | All three modules, timed | NTA Abhyas mocks in the real interface + previous papers, analysed question by question |
| 47–52 | Mocks only | Full 3-hour papers; revise from your mistake log and short notes, no new chapters |

## 6-month track (26 weeks)

Same parallel structure at double pace; for students already in Class 12 or repeating.

| Weeks | Module(s) | Work (free sources) |
|-------|-----------|---------------------|
| 1 | Diagnostic | One previous Paper 1 cold, timed; read the bulletin chapter list |
| 2–9 | [Physics](../../modules/ncert-physics.md) + [Chemistry](../../modules/ncert-chemistry.md) + [Maths](../../modules/ncert-mathematics.md), Class 11 | Core chapters only (mechanics, physical chemistry, algebra/trigo); NCERT exercises |
| 10–17 | [Physics](../../modules/ncert-physics.md) + [Chemistry](../../modules/ncert-chemistry.md) + [Maths](../../modules/ncert-mathematics.md), Class 12 | Electromagnetism, optics, modern + organic + calculus/vectors; exemplar per chapter |
| 18–21 | All three modules, second pass | Weak chapters from tagged PYQs; exemplar problems |
| 22–26 | Mocks only | NTA Abhyas + previous papers timed; mistake-log revision, no new chapters |

## Weekly rhythm (both tracks)

- Six study days, one lighter day for revision and rest; all three subjects every week, never one at a time.
- Every week: one timed sectional or full mock; log every mistake with its reason and re-solve it after
  a week, then after a month (see [study methods](../study-methods.md)).
- Every month: check remaining weeks against the official session dates and move unfinished chapters forward.
