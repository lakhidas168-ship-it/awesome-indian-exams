# Computer awareness

Counts for **10 exams** in this list (see the [overlap map](../resources/overlap-map.md)). Prepare it once.

## What it covers

- Computer fundamentals, hardware, software, memory
- Operating systems, MS Office basics
- Internet, networking, email, security basics
- Abbreviations and keyboard shortcuts asked in banking and SSC

## Where it counts

| Family | Exams |
|---|---|
| Engineering jobs: GATE, ESE, JE, PSU, state AE/JE | [RRB Junior Engineer (JE), Electrical](../exams/engineering/rrb-je-ee.md) |
| SSC | [Delhi Police Constable (conducted by SSC)](../exams/ssc/delhi-police-constable.md), [SSC CGL (Combined Graduate Level)](../exams/ssc/ssc-cgl.md), [SSC CHSL (Combined Higher Secondary Level)](../exams/ssc/ssc-chsl.md) |
