# Chemistry (NCERT Class 11–12)

Counts for **13 exams** in this list (see the [overlap map](../resources/overlap-map.md)). Prepare it once.

## What it covers

- Physical: mole concept, atomic structure, thermodynamics, equilibrium, kinetics, electrochemistry, solutions
- Inorganic: periodicity, bonding, s/p/d/f-block, coordination compounds
- Organic: GOC, hydrocarbons, functional groups, biomolecules, polymers
