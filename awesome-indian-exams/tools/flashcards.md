# Flashcards

Read the question, answer it in your head, then check. If you got it, the card comes back after 1, 3, 7, 16 and
then 35 days. If you missed it, it comes back tomorrow. A few minutes a day beats hours the night before.

!!! note "Runs on the website"
    This tool runs in your browser on the [website](https://lakhidas168-ship-it.github.io/awesome-indian-exams/tools/flashcards/) or in the
    [offline copy](https://lakhidas168-ship-it.github.io/awesome-indian-exams/download/awesome-indian-exams-offline.zip). On GitHub you only see this text.
